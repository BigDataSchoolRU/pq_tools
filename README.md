# pq_tools

Parquet file format tools and apps

## Очень краткое описание

Модуль и очень простое приложение для анализа метаданных `parquet` файла.

Приложения обладают следующими возможностями:

* анализ `parquet` файлов, расположенных локально или в Яндекс облаке (в объектном хранилище)
* показ общей информации о файле (размер, количество строк, распределение строк по группам строк, типы кодировок, наличие блюмфильтров, ...)
* показ детальной информации (статистики) по заданной колонке для заданной группы строк
* информацию в виде графика о взаимном размере отдельных частей файла (групп строк, колонки в пределах группы, блюмфильтров, футера)
* сводную статистику о колонке в пределах всего файла (в виде графика)
* возможность проверить срабатывание блюмфильтров для заданной колонки и заданного значения колонки.

Код разработан в виде модуля, который можно запускать как `Bottle` приложение или импортировать, например в Юпитер-ноутбук с тем, чтобы использовать функциональность в Юпитер-ноутбуке.

Для работы с метаданными `parquet` файла используется `DuckDB`.

Технически код разработан в виде "литературного ноутбука" (смотри соответствующий репозиторий). В данном репозитории поставляется готовый модуль. Тем самым необходимость использовать литературные ноутбуки является опциональной.

Более подробные описания содержатся в самих исходниках, а также в примерах.

## Структура репозитория

### Src: исходники

Основные исходники

* `app.py`: "запускалка" (см. установку и использование ниже)
* `lit_pq_tool.ipynb`: литературный ноутбук модуля (непосредственно оригинал, исходник или артефакт - то, что было создано руками
* `rus_strings.yaml`: английские строки и их перевод на русский язык
* `tpl_funcs.py`: модуль функций для шаблонов, пока это только для перевода (русский-английский)

#### Src/static: статика (bootstrap CSS и JS)

Включил на всякий случай (не правил, можно брать из CDN)

#### Src/views: шаблоны

Botleg позволяет работать с шаблонами. Для каждой страницы приложения сделан отдельный шаблон, чтобы не было зависимостей между шаблонами (шаблоны крайне просты).

### Examples: примеры

* `notebook_demo.ipynb`: пример Юпитер ноутбука, в котором показаны варианты использования всех функций модуля
* `item.parquet`: пример `parquet` файла

### Modules: сгенерированные модули

"Установочный" комплект

* `bottle.py`: Bottle framework (копия, он состоит из одного файла...)
* `pq_tool.py`: сгенерирован из литературного ноутбука

Эти модули нужно скопировать на `sys.path()`.

Модуль `pq_tool.py`  получен из ноутбука `lit_pq_tool.ipynb` (см. соответствующий репозиторий), поэтому он не содержит комментариев и не является "исходником".

## Быстрый старт

### Установка

Скопируйте модули `asm.py` и `lit.py` на `sys.path()` - как самый быстрый вариант в ту же директорию, где лежат остальные исходники (`app.py` и другие).

### Использование

В директории с исходниками (директория `Src` репозитория - там где `app.py` и другие) выполните команду

    python app.py

В браузере откройте URL

   localhost:8080

Выберите файл, например, item.parquet.
